# Project Documentation

Welcome to the markdown-docs example. This index page is the entry
point for the documentation set used as the qgb quality-gate target.

## Sections

- See `api.md` for the API reference.
- See `metadata.json` for machine-readable documentation metadata,
  which is validated against `schemas/metadata.schema.json`.

## Authoring conventions

All documentation pages start with an H1 header on the first line.
The metadata file declares the documentation set's version and the
list of pages.
